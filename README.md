# 📊 Sales Analysis Dashboard using Excel, Pandas & PySpark

## 🚀 Project Overview

This project focuses on analyzing sales data to extract meaningful business insights and build an interactive sales dashboard.

The raw dataset contained multiple issues such as:

* Incorrect date formats
* Missing values
* Dirty and inconsistent data
* Difficulties in extracting month and year information

To solve these problems, data transformation and cleaning techniques were applied using **Pandas**, **PySpark**, and **Microsoft Excel**.

After cleaning the data, different types of visualizations and pivot table analyses were created to understand:

* Customer growth over years
* Profit trends
* Regional sales performance
* Country-wise customer distribution
* Yearly sales analysis

This project can also be used as a portfolio project for data analysis and dashboard development.

---

# 🎯 Problem Statement

The objective of this project is to:

* Transform and clean raw sales data
* Handle incorrect and inconsistent date values
* Extract useful insights from the dataset
* Analyze customer growth and profit trends
* Create meaningful visual dashboards for decision-making

The dataset contained dirty data, especially in the `Order Date` column, where multiple date formats created issues while extracting:

* Month
* Year
* Time-based trends

To overcome these challenges, data preprocessing techniques were implemented using Python libraries and Excel tools.
